# 项目介绍

基于安卓java原生开发案例，新闻案例。

主要功能：

- sqlite数据库 增删改查
- json解析
- 网络请求
- 线性布局
- 瀑布流布局
- 主题色
- 登录界面
- 顶部多菜单布局
- 抽屉布局
