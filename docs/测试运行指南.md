## 运行单元测试

### 3.1 运行所有单元测试
#### 方法1: 使用 Gradle 命令
```bash
# 在项目根目录执行
./gradlew test

# Windows 系统
gradlew.bat test
```

#### 方法2: 使用 Android Studio
1. 打开项目
2. 右键点击 `app/src/test` 目录
3. 选择 "Run 'Tests in 'test''"
4. 或使用快捷键: `Ctrl+Shift+F10` (Windows/Linux) / `Cmd+Shift+F10` (Mac)

### 3.2 运行单个测试类
```bash
# 运行用户数据库测试
./gradlew test --tests "com.white.news.db.UserDbHelperTest"

# 运行历史记录测试
./gradlew test --tests "com.white.news.db.HistoryDbHelperTest"

# 运行实体类测试
./gradlew test --tests "com.white.news.entity.*"
```

### 3.3 运行特定测试方法
```bash
# 运行 UserDbHelperTest 中的某个测试
./gradlew test --tests "com.white.news.db.UserDbHelperTest.testRegister"
./gradlew test --tests "com.white.news.db.UserDbHelperTest.testLogin_Success"
```

## 查看测试报告

### 6.1 HTML 报告位置
测试运行完成后，HTML 报告生成位置：
```
app/build/reports/tests/test/index.html
```

### 6.2 查看报告
#### 方法1: 直接打开
```bash
# 在浏览器中打开报告
open app/build/reports/tests/test/index.html
```

#### 方法2: 在 Android Studio 中查看
1. 打开 Build 工具窗口 (View → Tool Windows → Build)
2. 点击 Build Output 中的测试链接
3. 或在 Run 工具窗口中查看测试结果

### 6.3 报告内容说明
- **Classes**: 测试类概览
- **Methods**: 测试方法详情
- **Packages**: 包级视图
- **Summary**: 测试统计摘要
- **Failed tests**: 失败测试详情

## 常见问题

### 8.1 Gradle 命令失败
**问题**: `./gradlew: Permission denied`

**解决**:
```bash
chmod +x gradlew
./gradlew test
```

### 8.2 测试超时
**问题**: API 测试超时或失败

**解决**:
- 检查网络连接
- 确认 API Key 是否有效
- API 可能有调用次数限制

### 8.3 测试数据清理
**问题**: 测试数据污染正式数据库

**解决**: 测试使用独立的测试数据库，无需担心。

### 8.4 部分测试失败
**问题**: 只运行失败的测试

**解决**:
```bash
# 只重新运行失败的测试
./gradlew test --tests "com.white.news.db.UserDbHelperTest" -Dtest.verbose
```

## 完整测试流程

### 9.1 推荐的测试执行顺序
```bash
# 1. 先运行数据库单元测试
./gradlew test --tests "com.white.news.db.*"

# 2. 运行实体类测试
./gradlew test --tests "com.white.news.entity.*"

# 3. 运行设计方法测试
./gradlew test --tests "com.white.news.testdesign.*"

# 4. 运行集成测试
./gradlew test --tests "com.white.news.UserFlowIntegrationTest"

# 5. 运行 API 测试
./gradlew test --tests "com.white.news.api.NewsApiTest"

# 6. 生成覆盖率报告
./gradlew jacocoTestReport
```

### 9.2 完整测试命令
```bash
# 运行所有测试并生成报告
./gradlew clean test jacocoTestReport
```

## Android Studio 界面操作

### 10.1 运行单个测试
1. 在编辑器中打开测试文件
2. 点击测试方法名左侧的绿色箭头
3. 或使用 `Ctrl+Shift+F10` (Windows) / `Cmd+Shift+F10` (Mac)

### 10.2 调试测试
1. 在测试方法名左侧点击设置断点
2. 右键选择 "Debug 'testName'"
3. 使用调试控制栏逐步执行

### 10.3 查看测试历史
1. Run → Show Coverage Results
2. 或按 `Alt+Shift+F6`

## 测试结果解读

### 11.1 符号说明
| 符号 | 含义 |
|------|------|
| ✓ | 测试通过 |
| ✗ | 测试失败 |
| ◉ | 测试进行中 |
| ○ | 测试被忽略 |

### 11.2 统计指标
- **Tests**: 总测试数
- **Passed**: 通过数
- **Failed**: 失败数
- **Ignored**: 忽略数
- **Duration**: 耗时
