# 核心模块因果图分析

## 一、登录模块 - 因果图

### 1.1 因果图符号说明

```
┌─────────────────────────────────────────────────────────────┐
│  因果图符号:                                                  │
│                                                              │
│  原因(原因节点)          结果(结果节点)                         │
│      ○                       ◉                              │
│                                                              │
│  恒等: 若原因出现，则结果出现                                   │
│       C1 ──────→ E1                                          │
│                                                              │
│  非: 若原因出现，则结果不出现                                   │
│       C1 ──○───→ E1                                         │
│                                                              │
│  或: 多个原因中任一个出现，则结果出现                            │
│       C1 ─┐                                                  │
│       C2 ─┼─────○───→ E1                                     │
│       C3 ─┘                                                  │
│                                                              │
│  与: 所有原因都出现，则结果出现                                 │
│       C1 ─┐                                                  │
│       C2 ─┼─────→ E1                                         │
│       C3 ─┘                                                  │
│                                                              │
│  互斥: 多个原因中有且仅有一个出现                               │
│       C1 ─┐                                                  │
│       C2 ─┼──⊕──→ E1                                         │
│       C3 ─┘                                                  │
└─────────────────────────────────────────────────────────────┘
```

### 1.3 逻辑关系

```
    约束条件:
    ┌────────────────────────────────────────────────────────────────┐
    │  E1 (登录成功) = C1 ∧ C2                                      │
    │           且 C1 ∧ C2 且仅 C1、C2 为真                           │
    │                                                                 │
    │  E2 (用户名不存在错误) = C3                                     │
    │           仅当 C3 为真时触发                                    │
    │                                                                 │
    │  E3 (密码错误) = C1 ∧ C4                                        │
    │           用户存在但密码错误                                     │
    │                                                                 │
    │  E4 (输入为空) = C5 ∨ C6                                       │
    │           用户名或密码任一为空                                   │
    │                                                                 │
    │  E5 (登录失败) = E2 ∨ E3 ∨ E4                                  │
    │           任一错误条件触发                                       │
    └────────────────────────────────────────────────────────────────┘
```
