# 注册与登录功能测试报告

## 一、注册功能 - 等价类划分测试

### 1.1 等价类划分表

| 输入条件 | 有效等价类 | 无效等价类 |
|---------|-----------|-----------|
| **用户名长度** | E1: 3-16位字符 | IE1: &lt; 3位<br>IE2: &gt; 16位 |
| **用户名字符** | E2: 字母、数字、下划线 | IE3: 特殊字符<br>IE4: 空格 |
| **密码长度** | E3: 6-20位字符 | IE5: &lt; 6位<br>IE6: &gt; 20位 |
| **用户存在性** | E4: 用户名不存在 | IE7: 用户名已存在 |
| **空值检查** | - | IE8: 用户名为空<br>IE9: 密码为空 |
