## 一、项目概述

### 1.1 项目背景

本项目是一款基于 Android 原生开发的新闻阅读应用，旨在为用户提供便捷的新闻资讯浏览服务。用户可以通过该应用浏览各类新闻、搜索感兴趣的内容、查看阅读历史，并管理个人账户信息。

### 1.2 项目目标

- 提供流畅的新闻浏览体验
- 支持多类别新闻内容展示
- 实现用户注册登录功能
- 提供新闻搜索和历史记录功能
- 保证用户数据安全

### 1.3 目标用户

- 普通新闻阅读爱好者
- 需要快速获取资讯的用户
- 追求简洁阅读体验的用户

## 二、功能需求

### 2.1 用户模块

#### 2.1.1 用户注册

| 功能编号 | FR-001 |
|---------|--------|
| 功能名称 | 用户注册 |
| 功能描述 | 新用户创建账户 |
| 优先级 | 高 |

**输入要求：**

| 字段 | 类型 | 长度限制 | 格式要求 |
|------|------|---------|---------|
| 用户名 | 字符串 | 3-16位 | 仅支持字母、数字、下划线 |
| 密码 | 字符串 | 6-20位 | 任意可见字符 |
| 确认密码 | 字符串 | 6-20位 | 必须与密码一致 |

**业务流程：**
```
用户输入用户名 → 系统验证用户名格式 → 检查用户名是否已存在
     ↓
用户输入密码 → 系统验证密码格式
     ↓
用户输入确认密码 → 系统验证两次密码一致性
     ↓
点击注册 → 创建账户 → 返回登录页面
```

**验证规则：**

| 验证项 | 规则描述 | 错误提示 |
|--------|---------|---------|
| 用户名非空 | 用户名不能为空 | "用户名不能为空" |
| 用户名长度 | 3-16位 | "用户名长度需在3-16位之间" |
| 用户名字符 | 仅字母、数字、下划线 | "用户名只能包含字母、数字、下划线" |
| 用户名唯一性 | 用户名不能重复 | "该用户名已被注册" |
| 密码非空 | 密码不能为空 | "密码不能为空" |
| 密码长度 | 6-20位 | "密码长度需在6-20位之间" |
| 密码一致性 | 两次密码必须相同 | "两次输入的密码不一致" |

**返回码说明：**

| 返回码 | 含义 |
|--------|------|
| > 0 | 注册成功，返回用户ID |
| -1 | 用户名格式验证失败 |
| -2 | 密码格式验证失败 |
| -3 | 用户名已存在 |

#### 2.1.2 用户登录

| 功能编号 | FR-002 |
|---------|--------|
| 功能名称 | 用户登录 |
| 功能描述 | 已注册用户登录系统 |
| 优先级 | 高 |

**输入要求：**

| 字段 | 类型 | 说明 |
|------|------|------|
| 用户名 | 字符串 | 已注册的用户名 |
| 密码 | 字符串 | 对应密码 |
| 记住密码 | 布尔 | 是否保存登录信息 |

**业务流程：**
```
用户输入用户名和密码 → 点击登录
     ↓
系统验证用户名存在性 → 验证密码正确性
     ↓
登录成功 → 保存用户信息 → 进入主页
```

**验证规则：**

| 验证项 | 规则描述 | 错误提示 |
|--------|---------|---------|
| 用户名非空 | 用户名不能为空 | "请输入用户名" |
| 密码非空 | 密码不能为空 | "请输入密码" |
| 用户名存在 | 用户必须已注册 | "该用户名未注册" |
| 密码正确 | 密码必须匹配 | "密码错误，请重新输入" |

**返回码说明：**

| 返回码 | 含义 |
|--------|------|
| 0 | 登录成功 |
| -1 | 用户名不存在 |
| -2 | 密码错误 |
| -3 | 用户名为空 |
| -4 | 密码为空 |

## 六、安全需求

### 6.1 用户认证

| 安全项 | 实现方式 |
|--------|---------|
| 密码存储 | 明文存储（实际项目中应加密存储） |
| 登录验证 | 用户名+密码匹配验证 |
| 会话管理 | SharedPreferences存储登录状态 |
| 数据隔离 | 按用户名隔离用户数据 |

### 6.2 输入验证

| 验证项 | 实现位置 |
|--------|---------|
| 用户名格式 | 后端UserDbHelper.validateUsername() |
| 密码格式 | 后端UserDbHelper.validatePassword() |
| 用户名唯一性 | 后端UserDbHelper.isUsernameExists() |
| 登录验证 | 后端UserDbHelper.loginVerify() |
